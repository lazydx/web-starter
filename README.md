# Web Starter

## What is this?

Web Starter is a Spring Boot starter library that provides standardized web application development features including response formatting, pagination limits, file handling, exception management, CORS configuration, and debugging support. It simplifies the development of REST APIs by automatically applying common patterns and best practices.

Key features include:
- **Standardized API Responses**: Automatic response wrapping in consistent format
- **Pagination Protection**: Built-in limits to prevent performance issues
- **File Management**: Secure upload/download with validation and multiple storage options
- **Exception Handling**: Consistent error responses with appropriate HTTP status codes
- **CORS Configuration**: Easy cross-origin resource sharing setup
- **Debug Mode**: Comprehensive request/response logging for development

## Prerequisites

- Java 17 or higher
- Spring Boot 3.2.5 or higher
