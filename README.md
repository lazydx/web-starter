# Web Starter

## What is this?
This is a starter module that provides common features for Spring Boot web applications.

## 🚀 Guide
### Summary
- **Standard response format**: Automatically wrap all API responses in a consistent format
- **Automatic pagination limiting**: Optimize performance by limiting page size and number of elements
- **CORS settings automation**: Manage CORS policies with simple settings
- **Global exception handling**: Consistent handling of business and system exceptions
- **Common utilities**: Provides frequently used utility classes

Check the [step-by-step GUIDE](GUIDE.md) to get the detailed explanation of the example codes.
